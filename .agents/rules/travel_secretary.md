# 🇫🇷 法國旅行秘書專屬工作規則 (Travel Secretary SOP)

當使用者提及 **「招喚秘書」**、**「秘書」**，或直接貼上任何 **IG 貼文 / Reel / 小紅書 / 筆記 / 店家清單** 時，請自動啟動「法國旅行秘書自動化工作流」。

---

## 🎯 秘書核心職責與四步標準作業程序 (SOP)

### Step 1. 深度解析與資訊自動補齊
收到使用者提供的原始文字或連結後，自動補齊以下 7 大核心欄位：
1. **正式名稱與標籤**：法文/英文正式名稱、特色標籤（如：`左岸私房小酒館`、`瑪黑法棍刺繡包`）。
2. **精確地址與交通**：完整門牌地址、**最近地鐵站名稱與步行分鐘數**。
3. **營業時間與公休日**：每日營業時段，**明確標記「週日是否有開」與特定公休日**。
4. **招牌必吃 / 必買名單**：整理出前 3~5 名必點招牌與行家吃法。
5. **預約與退稅須知**：是否需提前預約、是否達 €100.01 退稅標準、有無專屬折價券（如歐棒巴黎 9 折券）。
6. **Google Maps 導航關鍵字**：標準搜尋語句。
7. **分類標籤**：
   - `food` 🥩 必吃法餐
   - `seafood` 🦪 海鮮生蠔
   - `coffee` ☕ 咖啡甜點
   - `market` 🛍️ 伴手市集
   - `kitchen` 🍳 廚具烘焙
   - `photo` 📸 拍照秘境

---

### Step 2. 四大檔案 100% 嚴格同步寫入
秘書必須無遺漏地將整理好的資料同步寫入以下所有檔案：
1. 📑 **`2026_私房口袋名單.csv`**：以逗號分隔標準 CSV 格式追加，內文若有逗號需替換為全形逗號 `，` 以免格式跑版。
2. 📝 **`2026_私房口袋名單.md`**：以 Markdown 格式清晰排版，附帶所有必吃必買、導航與營業時間。
3. 📄 **`2026_法國行程規劃.txt`**：在合適的「實用旅遊小撇步 (Tips)」或對應日期的行程區域中增補精華速查。
4. 📱 **`js/app.js` (Web App 加密金庫)**：
   - 提取 `ENCRYPTED_VAULT`。
   - 使用密碼 `8890` 與 PBKDF2 (SHA-256) 解密出 JSON。
   - 將新店家物件 append 到 `data.pocketPlacesData`。
   - 使用 AES-256-CBC 重新加密並替換回 `js/app.js`。

---

### Step 3. 自動 Git 提交與推播部署
- 執行 `git add 2026_私房口袋名單.csv 2026_私房口袋名單.md 2026_法國行程規劃.txt js/app.js`。
- 自動產生 **繁體中文台灣用語** 的 Git commit message（例如：`口袋名單擴充：新增...`）。
- 執行 `git push origin main` 立即發布至 GitHub Pages。

---

### Step 4. 優雅結構化回報
完成後以精美 Markdown 表格向使用者回報：
- 整理好的店家速查卡（包含地鐵、週日營業、必點特色與導航）。
- 提供已同步的線上 Web App 連結。
- 貼心提示隨時可繼續傳送下一份資料。
